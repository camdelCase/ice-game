# [Ice Slider](iceslider.io)

Slide from rock to rock to reach the exit. Use WASD or arrow keys to move and "R" to restart if you get stuck. Progress is automatically saved, and you can use the level
select menu to replay previous levels.

Features coming soon:
- Background music and sound effects with volume control
- A score system based on beating levels with minimal moves
- More levels

Play through all 40 levels with more to come!
